# Sample data

Everything here is **fictional training data** generated by Aurelia Finance Lab for The Aurelia Grand,
a fictional 150-room hotel. It is not real hotel data and not an industry benchmark.

| Folder / file | What it is | How to recreate it |
|---|---|---|
| `capstone/` | The messy capstone dataset (raw rooms file with deliberate errors, hotel control totals, budget) | Capstone page → *Export the dataset (CSV)* |
| `workbooks/` | The four Excel practice workbooks, blank (no model answers) | Excel Lab → *Generate into a folder…*, or `Aurelia_Finance_Lab.exe --generate-workbooks DIR` |
| `Base_case_statements_annual.xlsx` | Formatted operating statement, income statement, balance sheet, cash flow and integrity checks for the Base case | Reports → *Statements to Excel (annual)* |

The completed reference workbooks are deliberately not included; generate them in the Excel Lab when
you want to check your work.
